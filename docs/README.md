# Guides

Read them in order the first time. Each guide is short and ends with the commands you need.

| # | Guide | What you learn |
|---|---|---|
| 1 | [Install](01_install.md) | set up Python, install, check that everything works |
| 2 | [The benchmark](02_benchmark.md) | the two hospital floors, the people, the robot, the tasks, the metrics, and how to change the cultural rules |
| 3 | [The navigation stack](03_navigation_stack.md) | how the route planner, the driver and the safety filter work together |
| 4 | [Training](04_training.md) | train one driver, or the whole campaign of the paper |
| 5 | [Evaluation](05_evaluation.md) | test a model with the paper's protocol, with and without a safety filter |
| 6 | [Ablations and robustness](06_ablations.md) | change one part at a time, and break the stack's assumptions on purpose |
| 7 | [Reproduce the paper](07_reproduce_the_paper.md) | rebuild every table and check every number from the saved results |
| | [Gazebo and ROS 2](../ros2/README.md) | run the stack in a physics simulator |
| | [Real robot](../real_robot/README.md) | run the stack on a car-like robot |
| | [Glossary](glossary.md) | every abbreviation and every short name used in the code |

Other material in this folder:
